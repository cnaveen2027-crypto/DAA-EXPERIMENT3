# DAA-EXPERIMENT3
Minimum Spanning Tree Visualizer (Flask + Render)
This project is a simple Flask web application that lets users input a graph (vertices and weighted edges) and computes the Minimum Spanning Tree (MST) using both Kruskal’s Algorithm and Prim’s Algorithm.
The results are displayed interactively on a webpage.

🚀 Features
Input number of vertices and edges via a web form.

Enter edges in the format u v w (where u and v are vertices, and w is the weight).

Compute MST using Kruskal’s and Prim’s algorithms.

Display MST edges and total cost neatly on the webpage.

Ready to deploy on Render.
